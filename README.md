# 🛠️ EZTool - Online Tool Shop

EZTool is a full-stack **e-commerce web application** developed to simplify the buying and selling of tools online. The platform provides a user-friendly shopping experience with secure authentication, product management, shopping cart functionality, and an admin dashboard for inventory and order management.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/FlameDash25/EZTool.git
```

### Move to XAMPP

Copy the project into

```
xampp/htdocs/
```

### Import Database

1. Open phpMyAdmin
2. Create a database named:

```
eztool
```

3. Import the SQL file.

### Configure Database

Update your database credentials inside:

```
config/database.php
```

### Run Project

Start

- Apache
- MySQL

Open

```
http://localhost/EZTool
```
